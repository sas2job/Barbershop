# Спецификация 005: ошибки JSON API

Публичные endpoint-ы `/api/v1` возвращают ошибки в формате:

```json
{ "error": "Ресурс не найден" }
```

Для отсутствующего сервиса или публичного токена используется статус `404`.
Для некорректных данных или недоступного слота используется `422`.

Ответы не содержат последовательные ID, SQL-детали, имена, телефоны или
публичные токены других записей.
