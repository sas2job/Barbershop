# Спецификация 002: бронирование

## Первый вертикальный срез

Клиент выбирает активную услугу, дату и свободный час, затем вводит имя и
телефон в формате `8-XXX-XXX-XX-XX`. После успешного резервирования запись
получает статус `confirmed` и доступна по случайному публичному токену.

## Расписание

- часовой пояс: `Europe/Moscow`;
- рабочие часы хранятся в `WorkingHour` и редактируются администратором;
- начальные часы: понедельник–пятница 08:00–20:00, суббота 09:00–20:00,
  воскресенье 09:00–19:00;
- начало записи возможно только в начале часа;
- один час резервируется целиком;
- одновременно доступны два места.

После каждой услуги планируется 5 минут уборки. Отдельный обязательный отдых не
резервируется: персонал отдыхает при отсутствии заявок.

## Модель данных

`BookingSlot` — уникальный часовой слот с вместимостью два места. `Booking`
ссылается на услугу и слот, хранит данные клиента, статус и уникальный
непредсказуемый публичный токен. Связь с мастером опциональна: мастера назначает
администратор после создания записи.

Заполнение слота выполняется в транзакции с блокировкой строки слота. Это
предотвращает превышение вместимости при конкурентных запросах.

## Следующие срезы

- отправка уведомлений.

Отмена и перенос доступны по публичному токену. Перенос создаёт новую запись и
аннулирует исходную в одной транзакции; при недоступности нового часа исходная
запись остаётся подтверждённой. Администратор может назначить или заменить
мастера через защищённый endpoint.
