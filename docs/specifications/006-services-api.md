# Спецификация 006: API каталога услуг

`GET /api/v1/services` возвращает только активные услуги. Необязательный
параметр `category` принимает `women` или `men` и фильтрует каталог по залу.

Успешный ответ имеет форму `{ "services": [...] }` и содержит идентификатор,
название, категорию, длительность и цены в копейках. Неактивные услуги не
возвращаются. Неизвестная категория отвечает `422` с полем `error`.
