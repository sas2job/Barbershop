# Спецификация 001: каталог услуг

Статус: Accepted

## Цель

Администратор может создать услугу, которая затем используется при расчёте свободного времени и создании записи.

## Исходные данные

Из предоставленных прайсов женского и мужского залов выбраны услуги:

| Категория | Услуга | Цена из прайса | Рабочая длительность |
|---|---|---:|---:|
| Женский зал | Модельная стрижка (мытьё + сушка) | 600–800 ₽ | 60 минут |
| Женский зал | Локоны (гофре, волна) + стайлинг | 1 400–1 700 ₽ | 90 минут |
| Женский зал | Плетение кос | 650 ₽ | 60 минут |
| Женский зал | Окрашивание в один тон | 2 400–4 000 ₽ | 120 минут |
| Мужской зал | Модельная стрижка (машинка + ножницы) | 550 ₽ | 45 минут |
| Мужской зал | Стрижка под машинку (2 и более насадки) | 450 ₽ | 30 минут |
| Мужской зал | Оформление бороды | 350 ₽ | 30 минут |
| Мужской зал | Камуфлирование седины «Estel Alpha Homme» | 600 ₽ | 30 минут |
| Мужской зал | Работа с применением шейвера | 50 ₽ | 30 минут |
| Мужской зал | Стрижка под одну насадку | 350 ₽ | 30 минут |
| Мужской зал | Стрижка наголо | 300 ₽ | 15 минут |
| Мужской зал | Модельная стрижка с элементами креатива | 600 ₽ | 45 минут |

Цены взяты из предоставленного изображения. Рабочая длительность предложена при проектировании и подтверждена вместе со спецификацией.

## Модель Service

Предлагаемые атрибуты:

| Атрибут | Тип | Назначение |
|---|---|---|
| `name` | string | Название услуги |
| `category` | enum | Раздел каталога: `women` или `men` |
| `duration_minutes` | integer | Длительность, используемая для расчёта слота |
| `price_from_cents` | integer | Минимальная цена в копейках |
| `price_to_cents` | integer | Максимальная цена в копейках |
| `active` | boolean | Доступна ли услуга для новых записей |

Для фиксированной цены `price_from_cents` равна `price_to_cents`.

## Бизнес-правила

- Название обязательно.
- Категория обязательна и должна входить в разрешённый список.
- Длительность должна быть положительным целым числом.
- Минимальная цена не может быть отрицательной.
- Максимальная цена не может быть меньше минимальной.
- Неактивная услуга сохраняется в истории, но недоступна для новой записи.
- Изменение цены или длительности услуги не должно менять уже созданные записи; позже запись будет хранить snapshot этих значений.

## Acceptance criteria

1. Администратор может создать услугу с фиксированной ценой.
2. Администратор может создать услугу с диапазоном цен.
3. Каталог можно отфильтровать по мужскому или женскому залу.
4. Создание услуги без названия или категории отклоняется.
5. Нулевая или отрицательная длительность отклоняется.
6. Максимальная цена меньше минимальной отклоняется.
7. Неактивная услуга не входит в список услуг для новой записи.
8. Денежные значения хранятся целыми копейками, без `float`.

## Не входит в первый срез

- отдельная таблица категорий и произвольное управление категориями;
- скидки;
- индивидуальная цена мастера;
- автоматический расчёт итоговой цены по длине волос;
- изображения услуги;

## Открытые вопросы

Открытых вопросов для первого среза нет.
