# ADR-0003: единый формат ошибок JSON API

## Статус

Принято.

## Решение

Все ошибки публичного API возвращаются JSON-объектом с полем `error` и
соответствующим HTTP-статусом. Отсутствующий ресурс получает `404` и единое
сообщение `Ресурс не найден`.

Решение реализовано в `Api::V1::BaseController`, чтобы endpoint-ы не
дублировали обработку `ActiveRecord::RecordNotFound`.

## Последствия

Клиенту не нужно разбирать HTML-страницы ошибок, а формат ответа одинаков для
availability и booking API. Тексты ошибок остаются пользовательскими и не
содержат внутренних идентификаторов, SQL или персональных данных.
